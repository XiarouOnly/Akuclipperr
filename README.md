# ClipForge AI - Functional YouTube Clipper

Aplikasi web Flask untuk mengunduh video YouTube dan memotongnya otomatis menjadi klip vertikal (9:16) siap upload untuk TikTok / Reels / Shorts.

## Cara Menjalankan
1. Install dependensi: `pip install -r requirements.txt`
2. Jalankan server: `python app.py`
3. Buka browser di `http://localhost:5000`
